# 日志查看器（log-viewer）

在插件窗口里实时预览 Cyrene 运行日志的插件。纯文件系统访问（`userData/logs/`），
不触碰应用内部模块，无需任何 API 配置。

## 功能

- **查看器窗口**（插件卡片「打开」按钮）：
  - 多文件切换：`cyrene.log` 主日志 + 滚动文件（.1/.2）+ TTS 等其他日志
  - 级别过滤：仅错误 / 警告+ / 信息+ / 全部，ERROR/WARN 彩色高亮
  - 关键词即时过滤；读取范围 64KB / 256KB / 1MB 可选
  - **实时跟随**：`fs.watch` 增量读取新条目自动滚入（Esc 暂停/恢复），文件滚动（rotation）自动重读
  - 堆栈等多行条目正确归组到所属条目
- **LLM 查询工具** `log-viewer_recent`：直接问 Cyrene
  「最近有什么报错？」「看看警告日志」——她会读日志尾部按级别汇总回答

## 安装

1. ZIP 导入：聊天窗口 → 插件 → 添加 → 选 `log-viewer-0.1.0.zip`；
   或把 `log-viewer` 文件夹复制到 `%APPDATA%\live2d-cyrene\plugins\`
2. 插件面板点「启用」
3. 点插件卡片的「打开」即可查看日志；对 Cyrene 说「最近有什么报错」验证工具

## 说明

- 日志目录：`%APPDATA%\live2d-cyrene\logs\`（与官方文件日志落盘位置一致）
- 主日志格式 `时间 级别 标签 消息`，单文件 5MB 滚动保留 3 份
- 插件只读，不修改、不上传任何日志内容

## 文件

| 文件 | 说明 |
|---|---|
| `manifest.json` | 插件清单（apiVersion 1，无 deps） |
| `index.cjs` | 文件列举、尾部读取与解析、fs.watch 增量推送、LLM 工具 |
| `ui.html` | 查看器窗口（过滤 / 搜索 / 跟随） |
